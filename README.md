# Калькулятор цен материалов ВСП

Веб-приложение на Streamlit: база материалов верхнего строения пути, расчёт отпускной цены с пересчётом тонн/штук и коммерческое предложение в PDF.

## Запуск

```bat
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Или двойной щелчок по `run.bat`.

Логин и пароль задаются в `.streamlit/secrets.toml` (скопируйте `secrets.toml.example`). Без этого файла вход закрыт.

База SQLite создаётся рядом с приложением в файле `vsp.db`. При первом запуске в неё попадают примеры рельсов, шпал и скреплений.

## Доступ с телефона и других устройств

Пока программа запущена на этом компьютере:

1. В той же Wi‑Fi сети откройте `http://IP-этого-ПК:8501` (например `http://192.168.1.11:8501`).
2. Из интернета с любого устройства нужен публичный адрес. Самые простые варианты:
   - [Streamlit Community Cloud](https://share.streamlit.io) — загрузить репозиторий, в настройках приложения добавить Secrets (логин/пароль) как в `secrets.toml`.
   - Компьютер остаётся включённым, туннель: [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) или ngrok на порт 8501. Ссылка вида `https://....trycloudflare.com` открывается с телефона и с другого города.
   - Свой сервер (VPS): установить Python, скопировать папку, `streamlit run app.py --server.address 0.0.0.0 --server.port 8501`.

Файл `vsp.db` живёт там, где запущено приложение. Если публикуете в облако — база будет облачная, не та, что на диске дома.

## Вкладки

- **База материалов** — цены закупки в гривнах; курс и валюта КП (USD, EUR, PLN, RUB) хранятся в SQLite.
- **Калькулятор заказа** — себестоимость в грн, отпускная цена КП = грн ÷ курс. В PDF клиент видит только цены в валюте КП, без закупки, маржи, налогов и курса.
